# Құрастыру және чат көмекші — жалғастыру есебі

## Іске асқан
- `/studio/summary` енді бос үстелден басталатын 3D кино. Бір GSAP timeline, 24-ке дейін қадам; тек таңдалған өнімдер анимацияға кіреді.
- Монитор тұғыры мен экраны бөлек clipped модельдер, жайылатын төсеніш, сыртқы құрылғылар, корпус, ішкі бөлшектер, кабельдер, желдеткіштердің іске қосылуы, RGB, шынының жабылуы, экран/жарық.
- Сахна барлық модель жүктелгеннен кейін басталады. Replay, Skip, жүйелік reduced-motion, толық 360° орбита, inside/exploded, конфигурация мен demo баға.
- Орбита артқы қабырғаға жеткенде бөлме cutaway ретінде ашылады. Алдыңғы камерада бөлме қалпында. Hero өзгермейді.
- Ішкі орнату кезіндегі бөлшек масштабы — 1, exploded үлкейту тек зерттеу үшін. GPU ұзындығы каталогтан, RAM саны жинақтан; ауамен кулер биіктігі және AIO радиатор түрі ажыратылады. Басқа өнімдер ортақ өкілдік модельді қолданады.
- Монитор 16:9/21:9 арақатынасына бейімделеді. ASUS ROG Strix XG27AQMR (300 Гц, 27″ QHD, Fast IPS) ресми бетпен тексеріліп қосылды. Каталог: 65 өнім. Бағасы demo.
- `/studio` — «Сетап көмекшісі»: kk/ru/en бюджет/мақсат/түстер, ASUS/жиілік және Logitech талаптары; каталог ID-лары, үйлесімділік, бюджет асып кетуі/каталогта жоқ талапты көрсету; «3D-ға қолдану» және кейін киноға өту.
- Көмекші детерминистік, құрылғыда жұмыс істейді. LLM endpoint іске асқан жоқ; API кілті қолданылмайды.

## Автоматты тексеріс
- `npm run build`: TypeScript + production build өтті.
- `npm run lint`: өтті.
- `npm run assets:validate`: 16 GLB, 14 лицензияланған түпнұсқа, 6.17 MB өтті.
- `npm run test:assembly`: 3 тест — тәуелділік/қуат қосу реті, таңдалмаған құрылғылар, replay.
- `npm run test:assistant`: 4 тест — тілдік сұраулар; 6 мақсат × 5 бюджет; ASUS 300 Гц + Logitech; жоқ/ойдан шығарылған өнімдер мен бюджеттен асу.

## Шектеулер және келесі жұмыс
- Нақты SKU үшін жеке модель әлі жоқ: өкілдік GLB, өнім өлшемі/салқындату түрі және таңдау ескеріледі. CPU/плата көрінісі AM4/X570 түпнұсқа геометриясы болып қалады.
- Орындық, AIO, бөлме, үстел, төсеніш және тұғырлар параметрлік. Ақ пернетақта бояуында таңбалар контраст шейдерімен сақталады.
- Чат парсері анық сөз үлгілерін таниды, еркін сұрақтардың бәрін түсінбейді. Бір негізгі мақсатты таңдайды; wishlist қанағаттанбаса ашық хабарлайды.
- PC Assembly Lab, желі/алгоритм/логика, сақталатын бағалау мен progress — келесі модульдер. Қазіргі сайт толық финал ретінде жарияланған жоқ.
- Firefox/Safari және нақты touch құрылғы тексерілмеген. Chromium/mobile viewport арқылы QA.
